# Тренажёр печати

[English documentation](README.md)

Запуск на Windows:

```powershell
py -3 -m pip install -r requirements.txt
.\run_typing_trainer.bat --lesson-length 200 --word-length 5 --language ru --charset ru
```

Язык интерфейса (`--language`) и набор символов (`--charset`, также `--layout`)
выбираются независимо. Доступны `ru` (русский), `en` (английский), `lv` (латышский).
По умолчанию интерфейс и тренировочный набор английские. Для русского интерфейса
укажите `--language ru` при запуске или выберите его клавишей F3.
Наборы включают буквы соответствующего языка и знаки пунктуации.

В главном окне:

- F1/F2 — уменьшить/увеличить длину слова.
- F3 — переключить язык интерфейса сразу, сохранив урок и статистику.
- F4 — переключить набор символов. Начатое слово нужно допечатать; новый набор
  применяется со следующего слова. До начала печати меняется сразу.
- PgUp/PgDn — прокрутить историю.
- Enter после завершения — новый урок с выбранными настройками.
- ESC — выход.

Выбранный набор отображается рядом с F4. Раскладку ввода Windows переключайте
обычным системным сочетанием клавиш: программа меняет задания, а не раскладку ОС.
Смена языка надписей не меняет набор упражнений.

Можно задать свой ряд символов:

```powershell
.\run_typing_trainer.bat --language en --chars "фываолдж" --word-length 4
.\run_typing_trainer.bat --language lv --charset lv
```

`--chars` имеет приоритет над `--charset`. В окне такой набор называется `custom`
и доступен через F4 вместе с готовыми наборами. Повторяющиеся символы удаляются.
Поддерживаются печатные символы шириной в одну ячейку терминала, включая кириллицу
и латышские буквы с диакритикой. Управляющие символы, отдельные комбинируемые знаки,
эмодзи и широкие иероглифы не поддерживаются.

Постоянные значения по умолчанию и готовые наборы редактируются в `config.py`:
`DEFAULT_LANGUAGE`, `DEFAULT_CHARSET`, `DEFAULT_SEQUENCE_LENGTH`,
`DEFAULT_LESSON_LENGTH`, `CHARSETS`. Переводы находятся отдельно в `languages.py`.
Изменения через клавиши действуют до закрытия программы.

Правильный ввод белый. При ошибке сначала отображается ожидаемый символ зелёным,
затем нажатый полужирным жёлтым. Пара считается одним вводом и одной ошибкой.
Таймер запускается с первого введённого символа каждого урока.

Строка задания по умолчанию имеет белый фон и чёрный текст. Цвет фона применяется
ко всей строке, включая пустое место после слова. Цвета можно изменить при запуске:

```powershell
.\run_typing_trainer.bat --target-fg black --target-bg cyan
```

Доступны `black`, `red`, `green`, `yellow`, `blue`, `magenta`, `cyan`, `white`.
Постоянные значения задаются через `TARGET_FOREGROUND` и `TARGET_BACKGROUND`
в `config.py`. В терминале без поддержки цветов используется инверсное выделение.

В строке задания показано только слово, следующая буква подчёркнута. Если
последнее нажатие было ошибочным, строкой ниже появляется подсказка `a→x`:
слева ожидаемый символ, справа нажатый. После правильного нажатия строка снова
пустая. Пробел в подсказке отображается как `␣`. Ошибки выделены полужирным
жёлтым; чтобы попробовать голубой, задайте `ERROR_FOREGROUND = "cyan"` в `config.py`.

В Windows Terminal размер шрифта задаёт профиль. Чтобы тренажёр запускался
со шрифтом 14, добавьте отдельный профиль в массив `profiles.list` файла
`settings.json` (открывается из настроек Windows Terminal):

```json
{
  "name": "Тренажёр печати",
  "commandline": "cmd.exe /c C:\\Projects\\typing-trainer\\run_typing_trainer.bat",
  "font": { "size": 14 }
}
```

Замените путь на фактический, затем запускайте профиль из меню новой вкладки. Другие профили
сохранят свой размер шрифта.
